# UK-National-Rail
This project was developed as part of the Maven Rail Challenge, where I acted as a BI Developer for National Rail. The goal was to build an exploratory dashboard to uncover key operational and revenue insights across passenger train services in England, Scotland, and Wales.
This project was developed as part of the Maven Rail Challenge, where I acted as a BI Developer for National Rail. The goal was to build an exploratory dashboard to uncover key operational and revenue insights across passenger train services in England, Scotland, and Wales.

🔍 Key Objectives

Identify the most popular routes

Determine peak travel times

Analyze revenue by ticket type and ticket class

📊 Key Insights

Clear visibility into high-demand routes driving passenger volume

Peak travel patterns identified across specific days and time bands

Revenue breakdown showed how different ticket types (Advance, Anytime, Off-Peak) contribute to overall income

Comparison between First Class and Standard ticket performance

🛠 Tools Used

Excel (Data Cleaning & Analysis)

Power BI (Interactive Dashboard Development)

Data Modeling & Visualization Techniques

💡 Outcome

The dashboard provides decision-makers with a clear view of travel demand trends and revenue distribution, enabling better operational planning, pricing strategies, and route optimization.
